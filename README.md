# Тетрадь

`Тетрадь` — отдельное нативное приложение для iPad и Mac. Ransel остаётся
самостоятельным проектом. Здесь на iPad есть один интерфейс: сам лист.

Лист заполняет экран, масштаб закреплён, а бледная клетка на iPad Pro 11"
равна половине физического сантиметра. UIKit принимает измерения Apple Pencil,
а PencilKit хранит и рисует готовые штрихи.
Панелей, обложек и списка файлов поверх бумаги нет. Маленький значок пера
раскрывает цвет, ластик, толщину и нижнюю границу непрозрачности. Бумага всегда
остаётся светлой, поэтому чернила сохраняют обычный цвет при любой системной
теме. При изменении размера окна лист целиком вписывается в него и остаётся по
центру.

## Жесты

| Действие | Результат |
|---|---|
| Apple Pencil | Пишет обычной ручкой; слабый нажим оставляет прозрачный след, сильный доводит его до полного цвета |
| Значок пера | Выбирает цвет, ластик, толщину и непрозрачность самого слабого следа |
| Двойное касание или сжатие Pencil | Переключает ручку и ластик |
| Касание двумя пальцами | Отменяет последнее движение Pencil на текущем листе |
| Удержание двумя пальцами | Последовательно отменяет движения, пока пальцы лежат на листе |
| Два пальца влево или вправо | Перелистывают страницы |
| Два пальца вверх или вниз | Меняют тетрадь |

Если листать вперёд за последнюю страницу, появляется один новый лист. Если
листать вниз за последнюю тетрадь, появляется одна новая тетрадь. Короткая
подсказка с номером исчезает сама. Выбранные цвет, толщина и нижняя граница
непрозрачности сохраняются между запусками приложения. Касания и удержание
двумя пальцами возвращают до 32 последних движений Pencil на каждом листе за
текущий запуск. Один палец на бумаге ничего не выбирает и не открывает меню.

## Как проходит мысль

```text
Apple Pencil
    |
    v
UIKit touch -> PKStroke -> PageDocument -> Network.framework -> файл на Mac -> MCP
                             ^                                      |
                             |                                      v
                             +---------- WebKit <---------- Markdown / SVG / JS
```

Владелец страницы — `PageDocument`. У него два независимых потока: штрихи
Pencil и слои агента. Поэтому поздний ответ агента не стирает новый штрих, а
новый штрих не возвращает удалённый агентом элемент. Mac хранит страницы
атомарными JSON-файлами в `~/Library/Application Support/Tetrad`.

iPad сам находит Mac через Bonjour. Сообщения идут напрямую по локальному
каналу через новый Swift API Network.framework; облачного посредника нет.
Оба приложения должны быть открыты, а при первом запуске iPad нужно разрешить
доступ к локальной сети.

## Запуск приложений

Нужны Xcode 27, XcodeGen 2.46 или новее и iPadOS/macOS 27.

```bash
cd /Users/amir/Documents/projects/Tetrad/Applications
xcodegen generate
open Tetrad.xcodeproj
```

В Xcode сначала запустите схему `TetradMac` на Mac, затем схему `Tetrad` на
iPad. Обе схемы используют команду разработки `VUNH73AYPY`; при переносе
проекта владелец сборки меняет `DEVELOPMENT_TEAM` в `Applications/project.yml`.

## MCP для агента

Сервер требует Node.js 20 или новее, работает через stdio и читает то же
хранилище, которым владеет Mac-приложение.

```bash
cd /Users/amir/Documents/projects/Tetrad/MCP
npm ci --ignore-scripts
codex mcp add tetrad -- /Users/amir/Documents/projects/Tetrad/MCP/run.sh
```

После добавления нужен новый сеанс Codex. В текущей машине сервер уже
зарегистрирован глобально под именем `tetrad`.

| Инструмент | Что он даёт агенту |
|---|---|
| `tetrad_context` | Текущие тетрадь, лист и версии |
| `tetrad_render_page` | PNG с клеткой и рукописными штрихами |
| `tetrad_read_page` | Markdown, HTML/SVG, CSS, JavaScript и состояние |
| `tetrad_put_markdown` | Прозрачный форматированный текст без оболочки |
| `tetrad_put_web` | Прозрачный интерактивный HTML/SVG/CSS/JS-слой |
| `tetrad_remove_elements` | Удаление выбранных слоёв с сохранением штрихов |

Маршрут агента короткий: сначала `tetrad_context`, затем
`tetrad_render_page` и `tetrad_read_page`, после этого запись с полученной
`agentRevision`. Если лист успел измениться, сервер отклоняет старую запись и
просит перечитать страницу.

Интерактивный слой читает состояние из `window.tetrad.state` и после действия
вызывает `window.tetrad.commit(nextState)`. WebKit сохраняет это состояние в
странице. Слой не имеет сетевого доступа: Content Security Policy разрешает
только встроенные стили, скрипты и `data:`-изображения.

## Граница первого выпуска

Транспорт ограничен локальным каналом и не выходит в интернет. Сейчас это
обычный TCP без TLS и без проверки личности второго устройства. Значит,
первый выпуск предназначен для личной доверенной сети. Следующий выпуск для
чужих или общих сетей должен добавить явное спаривание Mac и iPad, а затем
шифровать канал ключом этой пары.
