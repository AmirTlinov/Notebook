# Тетрадь

`Тетрадь` превращает iPad в лист бумаги и раскрывает этот лист в бесконечную
доску. Открытая тетрадь занимает весь экран. Щипок внутрь постепенно закрывает
её: движение пальцев напрямую управляет размером листа и поворотом обложки.
Дальше видна доска с тетрадями, стопками, рисунками и элементами агента. Обратный
щипок над тетрадью возвращает её лист.

```text
лист <-------- управляемый щипок --------> обложка <--------> бесконечная доска
```

Лист не имеет собственного зума. Пока он открыт, его масштаб закреплён, а
бледная клетка на полноразмерном iPad равна `0,5 см`. Под тетрадями лежит
отдельный холодно-серый рабочий холст с редкими точками. Он сохраняет ориентацию
в бесконечном пространстве, но больше не выглядит ещё одним листом тетради.

## Как пользоваться

| Действие | Результат |
|---|---|
| Apple Pencil с ручкой | Пишет на листе, обложке или доске; нажим меняет непрозрачность от выбранного минимума до полного цвета |
| Apple Pencil с ластиком | Стирает пройденную полосу; нажим расширяет контакт до выбранного максимума |
| Значок инструмента | Выбирает цвет, толщину и минимум непрозрачности ручки либо толщину ластика |
| Касание двумя пальцами | Отменяет последнее движение на открытом листе или текущей пространственной поверхности |
| Удержание двумя пальцами | Повторяет отмену каждые 95 мс, как удержание Backspace |
| Два пальца влево или вправо на открытом листе | Перелистывают страницы; движение вперёд за последнюю страницу создаёт одну новую |
| Щипок внутрь на листе | Непрерывно закрывает тетрадь и выводит на доску |
| Двойное касание тетради | Сразу раскрывает её в полный лист |
| Большой или быстрый щипок наружу над тетрадью | Подтверждает выбор, затем непрерывно раскрывает лист |
| Один или два пальца по доске | Двигают камеру; небольшой щипок только меняет масштаб вокруг места касания |
| Короткое удержание тетради и перетаскивание | Раскладывает её на доске; сброс на другую тетрадь создаёт стопку |
| `+` на доске | Создаёт тетрадь с первым листом и сразу предлагает название |
| `T` на выбранной обложке, затем касание | Вставляет редактируемый прозрачный текст |

Один палец на бумаге не открывает выделение или системное меню. Интерактивный
элемент, который явно добавил агент, остаётся нажимаемым. Цвет, толщина,
минимальная непрозрачность и размер ластика сохраняются между запусками.

## Кто чем владеет

```text
WorkspaceIndex
|-- тетради, страницы и текущий лист
|
BoardDocument
|-- положения тетрадей, стопки и элементы доски/обложек
|
SpatialInkJournal
|-- действия Pencil на доске и обложках
|
PageDocument
|-- drawingData   <- Pencil на одном листе
`-- elements[]    <- Markdown / SVG / CSS / JS агента

SessionPresence   <- камера, режим и текущий фокус
```

На iPad один Metal-холст владеет всеми видимыми пространственными чернилами.
Он показывает активный кончик ручки сразу, а после подъёма Pencil переносит ту
же геометрию в журнал. Линия не заменяется вторым рисунком. Ластик вычитается
тем же Metal-холстом во время движения, а PencilKit один раз вычисляет
сохраняемый итог после подъёма.

Один стабильный распознаватель, прикреплённый к сцене, владеет всей парой
пальцев. Поэтому он продолжает щипок даже в тот момент, когда лист уже стал
обложкой. Короткое окно наблюдения сравнивает совместный перенос пальцев с их
движением друг от друга: шум расстояния во время горизонтального свайпа больше
не закрывает тетрадь вместо перелистывания. Перед отменой или перелистыванием он
завершает текущее движение Pencil и ждёт его короткую очередь сохранения.

Пока пальцы лежат на экране, камера принадлежит только щипку. Одна замкнутая
формула сохраняет мировую точку из начала жеста точно под текущим центром двух
пальцев. Поле над обложкой сначала даёт лишь подсказку о возможной тетради.
Небольшое движение остаётся свободным приближением доски. Тетрадь получает
фокус после большого движения либо после достаточно быстрого и уже видимого
разведения пальцев. С этого кадра дальнейшее движение непрерывно управляет
раскрытием. После отпускания короткая пружина доводит сцену до целой доски,
закрытой обложки или полного листа.

## iPad, Mac и агент

```text
Apple Pencil -> Metal -> документ -> Network.framework -> Mac -> файлы -> MCP
                    ^                                      |
                    `----------- WebKit / Markdown ---------'
```

iPad находит Mac через Bonjour и передаёт изменения напрямую по локальному
каналу Network.framework. Mac показывает ту же сцену, следит за атомарными
файлами в `~/Library/Application Support/Tetrad` и создаёт два вида PNG:
изображение каждого листа и точное изображение текущей сцены. Рядом с текущим
PNG лежит квитанция версий камеры, доски, чернил и листа вместе с SHA-256 самой
картинки. MCP возвращает её только тогда, когда версии и отпечаток совпадают с
файлами, поэтому агент не получает старое или наполовину обновлённое изображение
под видом нового.

Каждое положение камеры несёт номер сессии, порядковый номер и фазу
`active` либо `settled`. Mac сразу показывает самый новый активный кадр, а на
диск сохраняет только завершённую сцену. Завершённый кадр нельзя вытеснить
началом следующего жеста. PNG для агента также строится только из завершённого
состояния и после короткой паузы изменений, поэтому движение камеры и письмо не
соревнуются с бесполезными промежуточными картинками.

Bonjour продолжает следить за списком Mac независимо от конкретного соединения.
Каждый найденный адрес получает свою задачу, исчезнувший адрес её завершает, а
listener и browser восстанавливаются после временной ошибки. Поэтому перезапуск
Mac больше не требует перезапуска приложения на iPad. При соединении сначала
приходят каталог, размещение и текущий завершённый вид, затем выбранный лист и
остальные данные. Полные рисунки одного листа, ещё ожидающие отправки, схлопываются
до самой новой ревизии.

Новая тетрадь публикуется в порядке `лист -> размещение -> каталог`. Старый
читатель может безопасно увидеть заранее подготовленное размещение, а после
появления тетради в каталоге её лист и место уже существуют.

## Запуск

Нужны Xcode 27, XcodeGen 2.46 или новее и iPadOS/macOS 27.

```bash
cd /Users/amir/Documents/projects/Tetrad/Applications
xcodegen generate
open Tetrad.xcodeproj
```

В Xcode сначала запустите `TetradMac` на Mac, затем `Tetrad` на iPad. Обе схемы
используют команду разработки `VUNH73AYPY`; другой владелец меняет
`DEVELOPMENT_TEAM` в `Applications/project.yml`. При первом запуске iPad нужно
разрешить доступ к локальной сети.

## MCP для агента

```bash
cd /Users/amir/Documents/projects/Tetrad/MCP
npm ci --ignore-scripts
codex mcp add tetrad -- /Users/amir/Documents/projects/Tetrad/MCP/run.sh
```

После добавления нужен новый сеанс Codex. На этой машине сервер зарегистрирован
как `tetrad`.

| Инструмент | Проверяемое действие |
|---|---|
| `tetrad_context` | Читает текущий режим, камеру, тетрадь, лист и видимые тетради |
| `tetrad_read_board` | Читает размещения, стопки, пространственные элементы и версии |
| `tetrad_read_notebook` | Читает одну тетрадь, её место, стопку и обложку |
| `tetrad_render_view` | Возвращает свежий PNG ровно того, что сейчас показывает Mac |
| `tetrad_create_notebook` | Создаёт тетрадь, первый лист и размещение |
| `tetrad_rename_notebook` | Меняет название на обложке |
| `tetrad_move_nodes` | Перемещает тетради и стопки в точных мировых координатах |
| `tetrad_stack_nodes` | Кладёт одну тетрадь на другую или в существующую стопку |
| `tetrad_put_spatial_markdown` | Добавляет прозрачный Markdown на доску или обложку |
| `tetrad_put_spatial_web` | Добавляет прозрачный интерактивный HTML/SVG/CSS/JS на доску или обложку |
| `tetrad_remove_spatial_elements` | Удаляет выбранные пространственные элементы, сохраняя Pencil |
| `tetrad_read_page` | Читает данные и агентские элементы листа |
| `tetrad_render_page` | Возвращает свежий PNG листа с клеткой и рукописью |
| `tetrad_put_markdown` | Добавляет прозрачный Markdown на лист |
| `tetrad_put_web` | Добавляет прозрачный интерактивный HTML/SVG/CSS/JS на лист |
| `tetrad_remove_elements` | Удаляет выбранные элементы листа, сохраняя Pencil |

Сначала агент читает контекст или доску, затем изображение и данные, после чего
передаёт полученную ревизию в изменение. Устаревшая запись получает конфликт и
должна перечитать владельца. Интерактивный слой читает
`window.tetrad.state` и сохраняет новое состояние через
`window.tetrad.commit(nextState)`. WebKit не имеет сетевого доступа.

## Проверка

```bash
cd /Users/amir/Documents/projects/Tetrad
./verify.sh
```

Маршрут проверяет Swift-домен, физическую клетку, слияние независимых потоков,
геометрию камеры и поверхностей, нажим, один финальный расчёт ластика, 16 MCP
инструментов, свежесть PNG, сборки macOS/iPadOS и живой Simulator. UI-проверки
пишут и стирают плотный лист, проверяют отзывчивость панели, возвращают лист из
поворота `портрет -> альбом -> портрет` без усадки, оставляют небольшой щипок
масштабом доски, открывают тетрадь большим щипком и отдельным двойным касанием.
Подробные системные контракты находятся в
[`docs/research.md`](docs/research.md).

## Граница локального прототипа

Канал остаётся внутри ближайшей сети, но текущий TCP ещё не шифруется и не
проверяет личность второго устройства. Поэтому приложение рассчитано на личную
доверенную сеть. Использование в общей сети требует явного спаривания устройств
и TLS с ключом этой пары.
