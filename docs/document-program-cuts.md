# Фрагменты программы на страницах

`DocumentLayoutRecord` связывает печатный прямоугольник с `sourceOffset` внутри
единого viewport. Одинаковые прямоугольники двух страниц могут показывать разные
части программы. Смещение обязательно в `DocumentBlockRegion`; отсутствие не
равнозначно нулю.

Источник геометрии — карта `\NotebookInteractive`, записанная TeX при shipout.
Нативный владелец переводит координаты в единицы поверхности и проверяет конечные
неотрицательные числа, размер viewport и непротиворечивость соседних фрагментов.
Допуск сравнения — 1/32 точки. SyncTeX отвечает за адрес исходника, не за
идентичность или размеры интерактивной области.

Один `DocumentBlockRuntime` исполняет экземпляр; продолжения получают его пиксели
и фактическое смещение, не запускают скрытые копии. Resize меняет viewport, а не
причинную версию файлов программы. Порядок освобождения: pause → checkpoint →
подтверждённая запись → release. См. [владельца программ](document-program-fragments.md).

`DocumentCutOriginTests` проверяет разные смещения при одинаковых прямоугольниках,
единицы, пропущенные/нечисловые координаты, переполнение и противоречивые фрагменты.
Проверка геометрии не заменяет жест и показ на физическом iPad.
