это исправление наблюдения, а не ускорение продукта на 129 с.

## Выход жестом без обратного приближения — 216

Установлена **0.3.146 (216)** на Mac и физическом iPad, код `044724d9`, GUI-314.
При сильном сведении пальцев
`NotebookZoomPassage.closed` безусловно возвращал `coverScale`, приближая уже
отдалённую обложку после отпускания. Теперь закрытие ограничивает масштаб сверху:
меньший достигнутый масштаб сохраняется, частичная обложка заканчивает закрытие.

Физический iPad: notebook native и настоящий жест (выход, повторное уменьшение,
отсутствие отскока, повторное открытие, сохранность перемещённого элемента) прошли;
document UI также прошёл. Document native первоначально сравнил временную A4
геометрию прямого fixture-открытия с измеренным Letter при повторном входе.
После ожидания установленной canonical геометрии перед исходным замером он прошёл;
финальный assert не изменён. Различий product/UI inputs между этими запусками нет.
Обычный cold-open readiness этим локальным сценарием не принят заочно.

Финальный повтор notebook UI прошёл на тех же исходниках для квитанции выпуска;
это один выбранный жест, не повтор полного набора. Тестовые app/runner удалены:
на iPad осталась только Notebook Lab 216. Обновление выполнено поверх 215,
без удаления контейнеров и ключей. Установленный Mac-помощник и текущая iPad presentation session отвечают `ready`.

## Установка и полная приёмка

Обновление согласованной Mac/iPad пары выполняется на месте: контейнеры,
идентичности и ключи сохраняются. Исторические архивы не открываются.
Schema27 вводится только согласованной парой; старый helper schema26 после
миграции не запускается против обновлённого workspace.

215 установлена 27 сентября в 22:24 UTC. Source SHA256:
`e117522d718ff8ca8fb77367d092f56a9b3ea4542cdefc790f6d024f0e4c5f40`.

`runtime/local-selection.json#`, `runtime/selection.json#`: новые сессии и выделение
после подключения. Подстановка их прежних hashes восстановила исходный SHA256
всех address/hash; остальные 40 669 записей, включая контент, неизменны.
Проверка SQLite выполнялась только чтением. iPad сообщил текущую authenticated
presentation session; новые пользовательские записи для проверки не создавались.

Full acceptance остаётся отдельной задачей GUI-190: десять повторов сценариев,
