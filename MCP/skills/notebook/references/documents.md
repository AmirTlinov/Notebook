# Запись блоков документа

`prepare.mjs document` записывает переданный текст, не выбирая структуру документа.

- Для нового документа: `target:{kind:"board",id}` и `anchor` на доске.
- Для добавления в существующий: `target:{kind:"document",id}` и необязательный
  `afterID` известного блока. Старые блоки сохраняются.
- `sections` — выбранные блоки в нужном порядке. У блока можно задать `id`,
  `body` либо `sourcePath` относительно входного JSON; сохраняется сам текст.
- `heading` необязателен; он добавляет Markdown-заголовок второго уровня.
  `kind` — `markdown` по умолчанию или `latex` для TeX-блока.
- `title` и `subtitle` необязательны; при наличии `title` создаётся титульный блок.
  `paperSize` и `preamble` задают печатное оформление нового документа.

Прочитанный блок меняется обычным `updateBlock`; `nb.export` готовит PDF.
