# Документы как удобный материал для мысли

Заготовки дают композиционную опору. Выбирай порядок и объём по смыслу:

- [Технический дизайн](../assets/documents/technical-design.md) — решение, устройство, существенные контракты.
- [Исследование](../assets/documents/research.md) — вопрос, материал, рассуждение и границы вывода.
- [Абстракт](../assets/documents/abstract.md) — компактное целое исследования.
- [Эссе](../assets/documents/essay.md) — тезис, развитие и возвращение к вопросу.

Текст, схемы, данные и источники можно собрать свободно. Заголовки, формулы,
таблицы, встроенные изображения и ссылки использует обычный renderer Notebook.
Каждый смысловой раздел остаётся отдельным редактируемым блоком.

Вход для `prepare.mjs document`:

```json
{
  "target":{"kind":"board","id":"UUID доски"},
  "anchor":{"tileX":0,"tileY":0,"localX":1200,"localY":400},
  "title":"Название исследования",
  "subtitle":"Краткий вопрос или главный результат",
  "sections":[
    {"id":"question","heading":"Вопрос","sourcePath":"question.md"},
    {"id":"evidence","heading":"Материал","body":"Текст, таблица или формула $x^2$."},
    {"id":"conclusion","heading":"Вывод","sourcePath":"conclusion.md"}
  ]
}
```

`sourcePath` читается при подготовке относительно JSON; в Notebook сохраняется
сам текст. `body` позволяет передать его прямо. Допустим `kind:"latex"` для
отдельного TeX-блока; для него удобно оставлять формулу без Markdown-заголовка.
Параметры `paperSize` и `preamble` доступны для печатного оформления.

Для продолжения существующего документа укажи `target:{kind:"document",id}`,
нужные `sections` и, при необходимости, `afterID` известного блока. Старые блоки
сохраняются. Для правки уже прочитанного раздела используй обычный `updateBlock`.

Исследовательские инструменты помогают найти материал и источники; структура
документа помогает сделать ход мысли видимым. Изображение можно включить через
`<figure><img src="data:image/…;base64,…"/><figcaption>…</figcaption></figure>`.
При нужном PDF существующий `nb.export` готовит печатный пакет из документа.
